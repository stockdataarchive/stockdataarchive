# Stock Data Archive

Historical US stock and ETF data in Parquet and CSV, including delisted symbols. Coverage varies by ticker.

[Website](https://stockdataarchive.com) · [Free samples](https://stockdataarchive.com/free-intraday-data/) · [MCP setup](https://stockdataarchive.com/mcp-server/)

## Research examples

[An opening range breakout, priced two ways](https://stockdataarchive.github.io/stock-data-archive/) compares minute-open and quoted bid/ask fills for one AAPL trade. The study includes Python source, input checks, downloadable results and controls for fees, slippage and latency.

[DuckDB queries and reproduction code](https://github.com/stockdataarchive/stock-data-archive) use the public sample files. No account or API key is required to run them.
