### [stockdataarchive.com](https://stockdataarchive.com)

Historical US stock and ETF data in Parquet and CSV: 1-minute bars, trades and top-of-book quotes, including delisted symbols. History starts in 2003; coverage varies by ticker.

[![Stock Data Archive website preview](https://raw.githubusercontent.com/stockdataarchive/stock-data-archive/main/docs/assets/website-preview.png)](https://stockdataarchive.com)

## Try the examples

- [Load the free AAPL sample](https://github.com/stockdataarchive/stock-data-archive/blob/main/examples/aapl_sample.py), check its trading sessions and export CSV.
- [Check ticker coverage through MCP](https://github.com/stockdataarchive/stock-data-archive/blob/main/examples/catalogue.py), including the dates on file for delisted symbols such as LEH.
- [Compare backtest fill assumptions](https://stockdataarchive.github.io/stock-data-archive/#finding) using the public bars and quotes, with Python source and a cost calculator.

The [examples repository](https://github.com/stockdataarchive/stock-data-archive) includes setup instructions. Public samples and MCP discovery need no account or API key. To use an agent, follow the [MCP setup guide](https://stockdataarchive.com/mcp-server/).

Coverage and file questions: [support@stockdataarchive.com](mailto:support@stockdataarchive.com).
